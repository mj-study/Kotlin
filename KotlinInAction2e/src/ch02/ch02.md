# 2장. 코틀린 기초

## 한눈에 보기

이 장은 Kotlin의 기본 문법을 다룬다. 함수 선언, 변수, 제어 구조(if, when, for)를 배우면서 Java와 다른 점을 이해한다. Kotlin에서는 if와 when이 문(statement)이 아니라 식(expression)이며, 함수도 식으로 간결하게 작성할 수 있다. 또한 문자열 템플릿으로 문자열 조합을 간단히 처리하고, 범위(range)와 progression을 사용해 반복문을 직관적으로 작성한다.

## 핵심 개념

### 함수 선언

Kotlin 함수는 `fun` 키워드로 선언한다. 파라미터는 `이름: 타입` 순서로 쓰고, 반환 타입은 파라미터 목록 뒤에 `: 타입`으로 표시한다.

```kotlin
package ch02

fun main() {
    println("메시지 출력")
}
```

**Java와 비교:**
- Java: `public static void main(String[] args)`
- Kotlin: `fun main()` - 더 간결하고, 파라미터가 없으면 생략 가능

### 블록 본문과 식 본문

함수 본문은 블록(block) 또는 식(expression) 형태로 작성할 수 있다.

```kotlin
package ch02

fun main() {
    val a = 3
    val b = 6
    println(blockFn(a, b))
    println(expressionFn(a, b))
}

// 블록(block)에서는 반환 타입 생략 불가능
fun blockFn(a: Int, b: Int): Int {
    return a + b
}

// 식(expression)에서는 반환 타입 생략 가능
fun expressionFn(a: Int, b: Int) = a + b
```

> 💡 **눈높이 설명**
>
> Java의 메서드는 항상 블록 `{}` 안에 return을 써야 한다. Kotlin은 함수 본문이 단일 식이면 `=`로 바로 연결할 수 있고, 이때 반환 타입을 컴파일러가 추론한다. 블록 본문에서는 타입 추론이 안 되므로 반환 타입을 명시해야 한다.

### 변수 선언: val과 var

Kotlin은 변수를 선언할 때 `val`(불변)과 `var`(가변) 두 가지 키워드를 사용한다.

- `val` (value): 초기화 후 재대입 불가능 (Java의 `final`)
- `var` (variable): 재대입 가능

```kotlin
fun main() {
    val immutable = 10
    // immutable = 20  // 컴파일 에러

    var mutable = 10
    mutable = 20  // OK
    println(mutable)
    // 출력: 20
}
```

> 💡 **눈높이 설명**
>
> 기본적으로 `val`을 사용하고, 꼭 필요할 때만 `var`를 쓰는 것이 권장된다. 불변 변수는 코드를 추론하기 쉽게 만들고, 멀티스레드 환경에서 안전하다. Java에서 `final`을 매번 쓰는 것이 번거로웠다면, Kotlin에서는 `val`이 기본 선택지가 된다.

### 문자열 템플릿 (String Template)

문자열 안에 변수나 식을 `$` 기호로 직접 삽입할 수 있다.

```kotlin
package ch02

fun main() {
    val input = readln()
    val name = if (input.isNotBlank()) input else "기본이름"

    // 기본 문자열 템플릿 사용
    print("이름은 $name")

    // 문자열 템플릿 중괄호 사용시 프로퍼티 접근 가능
    print("이름 길이는 ${name.length}자")
}
```

**Java와 비교:**
```java
// Java
String message = "이름은 " + name;
String length = "이름 길이는 " + name.length() + "자";
```

Kotlin은 `$변수` 또는 `${식}`으로 문자열을 조합한다. 중괄호 `{}`를 사용하면 프로퍼티 접근이나 메서드 호출 같은 복잡한 식도 삽입할 수 있다.

### if는 식이다

Kotlin의 `if`는 문(statement)이 아니라 식(expression)이므로 값을 반환한다. 따라서 삼항 연산자가 필요 없다.

```kotlin
fun main() {
    val score = 85
    val grade = if (score >= 90) "A"
                else if (score >= 80) "B"
                else "C"
    println(grade)
    // 출력: B
}
```

Java에서는 `String grade = score >= 90 ? "A" : "B";` 같은 삼항 연산자를 썼지만, Kotlin은 if 자체가 값을 반환하므로 더 읽기 쉽다.

### enum 클래스

Kotlin의 enum 클래스는 Java와 비슷하지만, 프로퍼티와 메서드를 가질 수 있다.

```kotlin
package ch02

import ch02.Color.*

enum class Color(val r: Int, val g: Int, val b: Int) {
    RED(255, 0, 0),
    ORANGE(255, 165, 0),
    YELLOW(255, 255, 0),
    GREEN(0, 255, 0),
    BLUE(0, 0, 255),
    INDIGO(75, 0, 130),
    VIOLET(238, 130, 238);

    fun rgb() = (r * 256 + g) * 256 + b
    fun printColor() = println("$this is ${rgb()}")
}

fun main() {
    println(getMnemoic(BLUE))
    // 출력: Battle
}

fun getMnemoic(color: Color) =
    when (color) {
        RED -> "Richard"
        ORANGE -> "Of"
        YELLOW -> "York"
        GREEN -> "Gave"
        BLUE -> "Battle"
        INDIGO -> "In"
        VIOLET -> "Vain"
    }
```

enum 클래스는 생성자 파라미터로 프로퍼티를 받을 수 있고, 메서드도 정의할 수 있다. enum 상수 목록과 메서드 사이에는 세미콜론(`;`)이 필요하다.

### when: Java switch의 강력한 대체

`when`은 Java의 `switch`와 비슷하지만 훨씬 강력하다. 임의의 객체를 대상으로 쓸 수 있고, 식으로 사용되며, 여러 값을 콤마로 묶을 수 있다.

```kotlin
package ch02

fun getMnemoic(color: Color) =
    when (color) {
        RED -> "Richard"
        ORANGE -> "Of"
        YELLOW -> "York"
        GREEN -> "Gave"
        BLUE -> "Battle"
        INDIGO -> "In"
        VIOLET -> "Vain"
    }

fun measureColor() = ORANGE

fun getWarmthFromSensor() =
    // when 식 대상을 변수로 캡처
    when (val color = measureColor()) {
        RED, ORANGE, YELLOW -> "warm ${color.r}" // 변수 프로퍼티 접근 가능
        GREEN -> "neutral"
        BLUE, INDIGO, VIOLET -> "cold"
    }
```

> 💡 **눈높이 설명**
>
> Java의 switch는 정수형, 문자열, enum만 처리하고 break를 빠뜨리면 의도치 않은 fall-through가 생긴다. Kotlin의 when은 break가 필요 없고, 여러 값을 콤마로 묶어 처리할 수 있으며, when의 대상을 변수로 캡처해서 분기 안에서 사용할 수도 있다.

### when에 인자가 없는 경우

when의 대상 없이 조건만 나열할 수도 있다. 이는 if-else 체인을 깔끔하게 표현하는 방법이다.

```kotlin
package ch02

fun main() {
    for (i in 1..100) {
        println(fizzBuzz(i))
    }
}

fun fizzBuzz(n: Int) = when {
    n % 15 == 0 -> "피즈버즈"
    n % 3 == 0 -> "피즈"
    n % 5 == 0 -> "버즈"
    else -> "$n "
}
```

when의 각 분기는 불리언 결과를 반환하는 조건식이다. 위에서 아래로 순서대로 검사하므로 `n % 15`를 먼저 검사해야 한다.

### 범위와 progression

Kotlin은 범위(range)를 표현하는 `..` 연산자를 제공한다.

```kotlin
package ch02

fun main() {
    // 1부터 100까지
    for (i in 1..100) {
        println(fizzBuzz(i))
    }

    // 100부터 1까지, 2씩 감소
    for(i in 100 downTo 1 step 2) {
        println(fizzBuzz(i))
    }
}

fun fizzBuzz(n: Int) = when {
    n % 15 == 0 -> "피즈버즈"
    n % 3 == 0 -> "피즈"
    n % 5 == 0 -> "버즈"
    else -> "$n "
}
```

- `1..100`: 1부터 100까지 (100 포함)
- `100 downTo 1`: 100부터 1까지 역순
- `step 2`: 2씩 증가/감소

### 컬렉션 순회: withIndex

컬렉션을 순회하면서 인덱스가 필요하면 `withIndex()`를 사용한다.

```kotlin
fun main() {
    val list = listOf("a", "b", "c")

    for ((index, value) in list.withIndex()) {
        println("$index: $value")
    }
    // 출력:
    // 0: a
    // 1: b
    // 2: c
}
```

**Java와 비교:**
```java
// Java
List<String> list = List.of("a", "b", "c");
for (int i = 0; i < list.size(); i++) {
    System.out.println(i + ": " + list.get(i));
}
```

Kotlin의 `withIndex()`는 인덱스와 값을 쌍으로 제공하므로 더 간결하다.

### in으로 범위 검사

`in` 연산자로 값이 범위에 속하는지 검사할 수 있다.

```kotlin
fun main() {
    val score = 85
    val result = when (score) {
        in 90..100 -> "A"
        in 80..89 -> "B"
        in 70..79 -> "C"
        else -> "F"
    }
    println(result)
    // 출력: B
}
```

`in`은 범위뿐만 아니라 컬렉션에도 사용할 수 있다.

```kotlin
fun main() {
    val vowels = setOf('a', 'e', 'i', 'o', 'u')
    println('a' in vowels)  // true
    println('b' in vowels)  // false
}
```

## Java와 비교

| 항목 | Java | Kotlin |
|------|------|--------|
| 함수 선언 | `public static void main(String[] args)` | `fun main()` |
| 블록 본문 | `{}` 안에 return 필수 | 식 본문 `=`으로 간결하게 표현 가능 |
| 변수 선언 | `final` 또는 일반 변수 | `val` (불변), `var` (가변) |
| 문자열 조합 | `"text " + variable` | `"text $variable"` (문자열 템플릿) |
| 삼항 연산자 | `condition ? a : b` | 없음 (if가 식이므로 불필요) |
| switch | 정수/문자열/enum만, break 필요 | when으로 모든 타입 처리, break 불필요 |
| for 반복 | `for (int i = 0; i < n; i++)` | `for (i in 1..n)` (범위 표현) |
| 범위 검사 | `x >= a && x <= b` | `x in a..b` |

## 헷갈리기 쉬운 점

### 블록 본문에서 타입 추론이 안 되는 이유

식 본문 `fun add(a: Int, b: Int) = a + b`는 타입 추론이 되지만, 블록 본문에서는 반드시 반환 타입을 명시해야 한다.

```kotlin
// OK: 식 본문은 타입 추론
fun add(a: Int, b: Int) = a + b

// 에러: 블록 본문은 타입 추론 안 됨
fun subtract(a: Int, b: Int) {  // 반환 타입 없음
    return a - b
}

// OK: 반환 타입 명시
fun subtract(a: Int, b: Int): Int {
    return a - b
}
```

블록 본문은 여러 문장을 포함할 수 있고, return이 여러 곳에 있을 수 있어서 타입 추론이 복잡하다. 따라서 명시적으로 반환 타입을 써야 한다.

### val은 불변 객체가 아니라 재대입 불가

`val`은 변수에 대한 재대입을 막을 뿐, 객체 자체를 불변으로 만들지 않는다.

```kotlin
fun main() {
    val list = mutableListOf(1, 2, 3)
    // list = mutableListOf(4, 5, 6)  // 에러: 재대입 불가
    list.add(4)  // OK: 객체 내부 변경은 가능
    println(list)
    // 출력: [1, 2, 3, 4]
}
```

`val`은 참조를 고정하지만, 참조하는 객체가 mutable이면 내용은 바뀔 수 있다.

### when은 모든 경우를 처리해야 한다

when을 식으로 사용할 때는 모든 가능한 경우를 처리해야 한다. 그렇지 않으면 컴파일 에러가 난다.

```kotlin
fun describe(color: Color) =
    when (color) {
        RED -> "빨강"
        BLUE -> "파랑"
        // 에러: GREEN, YELLOW 등이 처리되지 않음
    }

// OK: else로 나머지 처리
fun describe(color: Color) =
    when (color) {
        RED -> "빨강"
        BLUE -> "파랑"
        else -> "기타"
    }
```

### 범위의 끝은 포함된다

`1..10`은 1부터 10까지로, 10을 포함한다. 만약 10을 제외하려면 `until`을 사용한다.

```kotlin
fun main() {
    println(10 in 1..10)      // true
    println(10 in 1 until 10) // false
}
```

Java의 `for (int i = 0; i < 10; i++)`는 0부터 9까지이므로 `0 until 10`에 대응한다.

## 스스로 점검

<details>
<summary>1. 식 본문과 블록 본문의 차이는 무엇이며, 각각 언제 타입 추론이 가능한가?</summary>

식 본문은 `fun name() = expression` 형태로, 단일 식을 반환하며 타입 추론이 가능하다. 블록 본문은 `fun name(): Type { ... return value }` 형태로, 여러 문장을 포함할 수 있으며 반환 타입을 명시해야 한다.
</details>

<details>
<summary>2. val 변수에 저장된 mutable 컬렉션의 내용을 변경할 수 있는가?</summary>

있다. `val`은 변수에 대한 재대입을 막을 뿐, 참조하는 객체 자체를 불변으로 만들지 않는다. `val list = mutableListOf(1, 2, 3)`에서 `list.add(4)`는 가능하지만 `list = ...`는 불가능하다.
</details>

<details>
<summary>3. when과 Java의 switch의 주요 차이점 세 가지는?</summary>

1) when은 식으로 사용되어 값을 반환하지만, switch는 문이다. 2) when은 break가 필요 없고, 여러 값을 콤마로 묶어 처리할 수 있다. 3) when은 임의의 객체를 대상으로 쓸 수 있지만, switch는 정수/문자열/enum만 가능하다.
</details>

<details>
<summary>4. `1..10`과 `1 until 10`의 차이는?</summary>

`1..10`은 1부터 10까지로 10을 포함하고, `1 until 10`은 1부터 9까지로 10을 제외한다. Java의 `for (int i = 0; i < 10; i++)`는 `0 until 10`에 대응한다.
</details>

<details>
<summary>5. 문자열 템플릿에서 `$name`과 `${name.length}`의 차이는?</summary>

`$name`은 변수 자체를 삽입하고, `${name.length}`는 중괄호 안에 식을 넣어 프로퍼티 접근이나 메서드 호출 결과를 삽입한다. 복잡한 식이나 프로퍼티 접근에는 중괄호가 필요하다.
</details>
