# library-app conventions

- Entities hold business logic (`User.loanBook()`, `User.returnBook()`); validate in `init` blocks with `require`.
- Test fixtures are companion-object factories (`Book.fixture()`).
- JPA relationships need `var`; use `mutableListOf()` for `@OneToMany` with `orphanRemoval = true`.
- Never expose entities in API responses; use request/response DTOs in `dto/`.
- QueryDSL: custom repositories are `@Component` classes in `repository/` (separate from Spring Data interfaces in `domain/`); Q-types are generated by KAPT.
- Tests: `@SpringBootTest` with constructor injection (`@Autowired constructor`), reset state in `@AfterEach` via `deleteAll()`, prefer AssertJ, use `@DisplayName`.
