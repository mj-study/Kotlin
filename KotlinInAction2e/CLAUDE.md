## Commit Message Style

Conventional format based on git history:
- `feat.` - New features or enhancements
- `chore.` - Dependency updates or tooling changes
- `migration.` - Java-to-Kotlin conversions
- `test.` - Test additions or modifications
- Use Korean or English descriptions
- Examples:
  - `feat. Book 통계 - 타입별 권수, 대출 권수`
  - `migration. controller Java -> Kotlin`
  - `chore. QueryDsl 의존 추가`
